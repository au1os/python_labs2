### 2. Описание реализованной иерархии классов

#### Базовый класс: `Apartment` (из ЛР-1)
Класс Apartment хранит данные о квартире: площадь, цена аренды, адрес, срок аренды, а также логическое состояние (арендована/свободна).

**Основные методы:**
- `calculate_monthly_payment()` - расчёт ежемесячного платежа
- `is_expensive(threshold)` - проверка на дороговизну
- `rent()` / `vacate()` - изменение состояния аренды

#### Производный класс 1: `StudioApartment`
Квартира-студия с дополнительными атрибутами:
- `_has_kitchenette` (bool) - наличие кухонного уголка
- `_studio_type` (str) - тип студии (стандарт, комфорт, премиум)

**Переопределённые методы:**
- `calculate_monthly_payment()` - с повышающими коэффициентами для премиум и комфорт студий
- `__str__()` - расширенное представление с информацией о студии

**Новые методы:**
- `is_suitable_for_students()` - проверка пригодности для студентов

#### Производный класс 2: `LuxuryApartment`
Элитная квартира с дополнительными атрибутами:
- `_has_parking` (bool) - наличие парковочного места
- `_floor_level` (str) - уровень этажа (низкий, средний, высокий, пентхаус)
- `_luxury_features` (List[str]) - список элитных особенностей

**Переопределённые методы:**
- `calculate_monthly_payment()` - с повышающими коэффициентами за пентхаус, высокий этаж, парковку и особенности
- `__str__()` - расширенное представление с информацией об элитности

**Новые методы:**
- `add_luxury_feature(feature)` - добавление особенности
- `is_vip()` - проверка VIP статуса
- `is_suitable_for_family()` - проверка пригодности для семей

### 3. Обновлённый класс коллекции `ApartmentCollection`

Коллекция теперь поддерживает полиморфизм и может хранить разные типы квартир.

**Новые методы для работы с типами:**
- `get_only_studios()` - получить только студии
- `get_only_luxury()` - получить только элитные квартиры
- `get_only_basic()` - получить только базовые квартиры
- `get_by_type(apartment_type)` - универсальная фильтрация по типу
- `count_by_type()` - подсчёт количества квартир каждого типа
- `calculate_total_monthly_income()` - расчёт общего дохода (использует полиморфизм)
