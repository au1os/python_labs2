# Лабораторная работа №6
## Generics и typing

### Цель работы
- Научиться создавать обобщённые (generic) классы с использованием `TypeVar`
- Освоить использование протоколов (`Protocol`) для структурной типизации
- Реализовать универсальный контейнерный класс с поддержкой типизации
- Применить продвинутые возможности модуля `typing`

### Предметная область
Используется тот же класс `Apartment` из ЛР-1, что и в предыдущих работах.

### Реализованные классы

#### 1. Generic-класс `TypedCollection[T]`
Обобщённый контейнерный класс, который может хранить объекты любого типа `T`.

**Основные методы:**
- `add(item: T)` - добавить объект
- `remove(item: T)` - удалить объект
- `get_all() -> List[T]` - получить все объекты
- `get_at(index: int) -> T` - получить объект по индексу
- `find(predicate) -> Optional[T]` - найти первый подходящий элемент
- `filter(predicate) -> List[T]` - отфильтровать элементы
- `map(transform) -> List[R]` - преобразовать элементы

**Магические методы:**
- `__len__()` - количество элементов
- `__iter__()` - итератор
- `__getitem__(index)` - доступ по индексу
- `__str__()` - строковое представление

#### 2. Протоколы (структурная типизация)

**`Displayable`** - для объектов, которые могут быть отображены:
```python
class Displayable(Protocol):
    def display(self) -> str:
        ...
```

**`Scorable`** - для объектов, которые могут быть оценены:
```python
class Scorable(Protocol):
    def score(self) -> float:
        ...
```

#### 3. Специализированные коллекции

**`DisplayableCollection`** - коллекция для объектов, реализующих `Displayable`:
- `display_all()` - вывод всех объектов

**`ScorableCollection`** - коллекция для объектов, реализующих `Scorable`:
- `get_scores() -> List[float]` - получить все оценки
- `get_average_score() -> float` - средняя оценка

### Сценарии использования

#### Сценарий 1: TypedCollection с Apartment
- Создание типизированной коллекции `TypedCollection[Apartment]`
- Добавление объектов
- Использование `find()`, `filter()`, `map()` с разными предикатами
- Демонстрация валидации типов

#### Сценарий 2: Протоколы Displayable и Scorable
- Проверка, что `Apartment` реализует `Displayable` (через `__str__`)
- Создание `DisplayableCollection` с квартирами
- Создание `ScorableCollection` с объектами, имеющими рейтинг
- Вычисление средней оценки

### Ключевые особенности реализации

1. **TypeVar** - для создания обобщённых типов:
   - `T` - основной тип элементов
   - `R` - тип результата преобразования
   - `D` - тип с ограничением `Displayable`
   - `S` - тип с ограничением `Scorable`

2. **Protocol** - для структурной типизации:
   - Классы не должны явно наследоваться от протокола
   - Достаточно наличия соответствующих методов

3. **Generic** - для создания параметризованных классов:
   - `TypedCollection[T]` работает с любым типом `T`
   - `DisplayableCollection` работает только с `Displayable`
   - `ScorableCollection` работает только с `Scorable`
